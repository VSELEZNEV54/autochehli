# Автостиль — прототип редизайна 1avtochehol.ru

Статический фронт без бэкенда: HTML + CSS + ванильный JS. Открывается двойным кликом
по `index.html` или через любой статический сервер (`python3 -m http.server 8791`).

## Страницы

| Файл | Что это | SEO-роль |
|------|---------|----------|
| `index.html` | Главная: баннер-слайдер с предложениями, категории, марки, хиты, промо, пошаговый калькулятор, материалы, преимущества, отзывы, FAQ, SEO-текст | Брендовые и общие запросы |
| `car.html?m=toyota_camry-xv70` | Страница автомобиля (посадочная под рекламу): H1, галерея, конфигуратор с ценой, комплектация, табы, похожие, FAQ, JSON-LD | «чехлы на Toyota Camry XV70» |
| `brand.html?b=toyota` | Страница марки: популярные модели, фильтры, список моделей | «авточехлы на Toyota» |
| `catalog.html` | Резервная страница всех марок (для SEO и без JS). В интерфейсе каталог открывается мега-меню из шапки | «авточехлы по маркам» |

Полный список страниц — ниже.

Страницы марки и авто гидратируются из `?b=` / `?m=` — можно открыть любую из 552 моделей.
На реальном сайте это будут серверные страницы с теми же шаблонами и ЧПУ-адресами.

Корзина и избранное хранятся в localStorage браузера: кнопки «В корзину» на страницах авто, в калькуляторе
и в разделах товаров реально наполняют корзину, счётчики в шапке обновляются, оформление ведёт на `thanks.html`.
Выбор города в верхней строке — модальное окно с поиском, город запоминается.
Все формы (вопрос, контакты, дилеры, отзыв, подписка) отправляются «в демо»: показывают уведомление и очищаются.

## Как добавить статью или страницу

1. Создайте `content/<имя>.html`: первой строкой JSON-шапка в комментарии
   `<!-- {"title": "...", "description": "...", "page": "blog"} -->`, дальше HTML тела страницы.
   Боковую колонку можно вставить строкой `<!-- @include partials/blog-aside.html -->`.
2. Для статьи блога добавьте запись в `window.AS_POSTS` в `js/products.js` — она появится в списке блога,
   на главной и в блоках «Читайте также».
3. Запустите `python3 build.py` — страница соберётся в корень с общей шапкой и футером.

## Каталог в шапке

Кнопка «Каталог» открывает мега-меню: слева список марок (популярные первыми), при наведении справа
раскрываются модели с годами и ссылками на страницу модели. На мобильных та же кнопка открывает
шторку с вкладкой «Каталог марок» (аккордеон марка → модели).

## Общие блоки

Шапка и футер лежат в `partials/header.html` и `partials/footer.html` и вставляются в страницы
между маркерами `<!-- @header -->` / `<!-- @footer -->` скриптом:

```
python3 build.py
```

После правки partials запустите сборку — обновятся все страницы.

## Данные

`js/data.js` — 41 марка и 552 модели, собранные с текущего сайта клиента (sitemap + списки в каталоге).
Для каждой модели: slug, название, годы, класс для ценообразования (b / c / d / suv / mpv / pickup),
кириллические синонимы для поиска, фото-заглушка.

## Что демонстрационное

- Цены (`js/app.js`, объекты `BASE` / `MATERIALS` / `OPTIONS`) — правдоподобные, но не от клиента.
- Скидки «−15 %», рейтинги, количество отзывов, тексты отзывов, «гарантия 12 месяцев» — заглушки.
- Заказ не уходит на сервер: корзина и формы работают в браузере, после «Оформить заказ» открывается страница «Заказ принят».
- Фото ковриков EVA взяты с сайта prime-avto.ru как иллюстрации (заменить на свои).
- PDF сертификатов на странице «О компании» — заглушки.
- Фото и логотипы марок — с сайта клиента (`assets/`).
